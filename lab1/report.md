## 1. Описание процесса
Процесс включает проверку пациента в базе, создание медкарты (если ее нет), выбор врача, проверку свободных мест в расписании и выдачу талона.

## 3. Сравнение версионирования (git diff)
Я добавила новый шаг («Выдача талона в руки») в BPMN и посмотрела изменения через git diff. 
Для текстового файла .bpmn Git показал точную строчку кода с новым названием блока. Для картинки .png Git только выдал надпись Binary files differ, так как не может заглянуть внутрь изображения.
