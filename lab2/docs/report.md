## Ачивка 3. JWT-логин

Реализована схема аутентификации по JWT в Node-RED:

- POST /login — принимает логин/пароль, возвращает JWT-токен (HS256, срок 1 час)
- GET /me — защищённый эндпоинт, требует валидный токен в заголовке Authorization

Использованные ноды:
- node-red-contrib-jsonwebtoken (jwt-sign, jwt-verify)
- function, switch, http in, http response

Проверено через curl:
- Успешный логин → 200 + токен
- Неверный логин → 401
- /me с токеном → 200 + данные пользователя
- /me без токена → 401
