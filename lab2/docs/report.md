# Отчет по лабораторной работе №2
Тема: Технологии визуального программирования (Node-RED)
Студентка: Сотникова

## 1. Краткое описание выполненной работы
В ходе лабораторной работы я развернула платформу визуального программирования Node-RED с использованием Docker. Я разработала и протестировала 12 потоков (flows), охватывающих базовую обработку данных, ветвление, работу с внешними API, протокол MQTT, создание собственных HTTP эндпоинтов, графический веб-интерфейс Dashboard, интеграцию с Telegram Bot API, сохранение данных в файл и управление контекстом.

## 2. Способ установки и версии компонентов
* Способ развертывания: Docker Desktop (контейнер с постоянным томом /data)
* Node-RED version: v5.0.7
* Node.js version: v24.20.0

## 3. Освоенные узлы (ноды)
* Базовые: inject, debug, function, switch, change, template.
* Сетевые: http request, mqtt in, mqtt out, http in, http response.
* Хранилище: file in, file out (работа с файловой системой).
* Расширения: node-red-dashboard (gauge, chart), node-red-contrib-telegrambot (receiver, sender).

## 4. Примеры использованных AI-промптов
* "Напиши JS-код для ноды function в Node-RED с циклом for и проверкой четности чисел, возвращающий объект"
* "Составь Mustache-шаблон для ноды template, подставляющий имя студентки и баллы"
* "Напиши функцию для обработки команд /start и /help для Telegram-бота в Node-RED"

## 5. Выводы
Я освоила low-code инструмент Node-RED. Научилась проектировать событийные архитектуры, работать с потоками сообщений (msg), настраивать взаимодействие через REST и MQTT, а также быстро создавать UI-интерфейсы и ботов. Все поставленные задачи выполнены мною в полном объеме.
