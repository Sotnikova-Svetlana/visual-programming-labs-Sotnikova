# Работа с Redis
В ходе лабораторной работы был поднят in-memory кеш Redis через Docker. В n8n созданы credentials с параметрами host.docker.internal:6379.
Собраны два workflow:
1. Запись ключа sotnikova со значением пароля и его последующее чтение (Get).
2. Удаление ключа sotnikova (Delete) и проверка его отсутствия (база возвращает пустой объект).
